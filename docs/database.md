# Database

PostgreSQL 16 with the `uuid-ossp` and `postgis` extensions. All IDs are UUIDs generated by `uuid_generate_v4()`. All timestamps are `TIMESTAMPTZ` defaulting to `NOW()`.

---

## Schema Overview

```
Core / Auth          → universities, university_settings, users, profiles,
                       invitations, user_sessions
Social Feed          → posts, comments, reactions, follows, saved_posts,
                       tags, post_tags, polls, poll_options, poll_votes
Job Board            → jobs, job_applications, saved_jobs
Events               → events, event_rsvps
Groups / Clubs       → groups, group_members
Messaging            → conversations, conversation_participants, messages
Notifications & News → notifications, news
Campus Tools         → lost_and_found, courses, user_courses,
                       shuttle_routes, shuttle_locations
Engagement           → mentorship_requests, badges, user_badges, reports
```

## Migrations

```bash
# Create a new migration
pnpm --filter api db:migrate:make add_<description>
# e.g. pnpm --filter api db:migrate:make add_post_hashtags

# Run all pending migrations
pnpm --filter api db:migrate

# Rollback last batch
pnpm --filter api db:rollback

# Full reset (dev only — destructive)
pnpm --filter api db:reset
```

### Migration file conventions
- Filename: `YYYYMMDDHHMMSS_description.ts`
- Location: `apps/api/src/db/migrations/`
- **Never edit a committed migration.** Create a new one that corrects it.
- Always write the `down` function to make rollbacks reliable.
- For large tables (>100k rows), add new nullable columns and backfill in a separate migration or background job.

### Adding an index in a migration
```typescript
export async function up(knex: Knex) {
  await knex.schema.table('posts', (table) => {
    table.index(['university_id', 'created_at'], 'idx_posts_university_created');
  });
}
export async function down(knex: Knex) {
  await knex.schema.table('posts', (table) => {
    table.dropIndex(['university_id', 'created_at'], 'idx_posts_university_created');
  });
}
```

## Naming Conventions

| Thing | Convention | Example |
|-------|-----------|---------|
| Tables | snake_case, plural | `job_applications` |
| Columns | snake_case | `university_id`, `created_at` |
| Indexes | `idx_{table}_{column(s)}` | `idx_posts_university` |
| Foreign keys | `{referenced_table_singular}_id` | `university_id`, `author_id` |
| Boolean flags | `is_{state}` | `is_active`, `is_published` |
| Timestamps | `{action}_at` | `created_at`, `resolved_at` |
