## Features built

### GroupsPage (`src/pages/GroupsPage.tsx`)
- Filter bar: All / Department / Club / Batch / Research / Interest (scrollable pill nav)
- Infinite scroll via `useInfiniteQuery` → `GET /groups?page=N&type=...`
- Responsive auto-fill grid (`minmax(260px, 1fr)`) of `GroupCard` components
- Each card: avatar (seeded initials fallback), name, colour-coded type badge, member count, Join/Leave button
- Join/Leave: `POST /groups/:id/members` / `DELETE /groups/:id/members/me` with optimistic cache invalidation
- Skeleton grid on initial load, empty state, and "N groups shown" end divider

### GroupDetailPage (`src/pages/GroupDetailPage.tsx`)
- Back-to-groups link
- `GroupHeader`: cover image (indigo gradient fallback), overlapping avatar, name, member count, Join/Leave
- Two-tab nav: **Feed** / **Members**
- `FeedTab`: infinite-scroll `GET /posts?groupId=:id`, renders existing `PostCard`
- `MembersTab`: infinite-scroll `GET /groups/:id/members`, avatar + name + role badge (Admin = orange, Mod = indigo; plain member badge omitted for visual cleanliness)

### Skeleton component library (`src/components/skeletons/`)
Four shimmer skeleton components using `@keyframes shimmer { 0%,100%{opacity:.4} 50%{opacity:.9} }` (keyframes added to `src/styles/index.css`). Each matches the exact dimensions of the real card it replaces.

| File | Matches |
|---|---|
| `SkeletonPost.tsx` | `PostCard` — avatar + 2 author lines + 3 body lines + 3 reaction pill chips |
| `SkeletonJobCard.tsx` | `JobCard` — 44×44 logo square + 3 text lines + 3 tag chips |
| `SkeletonEventCard.tsx` | `EventCard` — 80px cover block + title/location + footer buttons |
| `SkeletonConvRow.tsx` | `ConversationRow` — 42px avatar + name/time row + preview line |

All four wired into their respective list pages (FeedPage, JobsPage, EventsPage, ConversationList) — 3 instances rendered while `isLoading`, 2 while `isFetchingNextPage`.

### EmptyState (`src/components/EmptyState.tsx`)
Shared empty state component. Props: `icon: LucideIcon`, `title: string`, `description?: string`, `action?: { label, onClick }`.

Wired into:
- `FeedPage` — Rss icon, "Nothing here yet"
- `JobsPage` — Briefcase icon, "No jobs found" (description adapts to search vs. no filter)
- `EventsPage` — CalendarX icon, "No events this week" (description adapts to date filter)
- `ConversationList` — MessageCircle icon, "Start a conversation"

Replaced all inline copy-paste empty-state divs in those files.

### ErrorBoundary (`src/components/ErrorBoundary.tsx`)
React class component (`getDerivedStateFromError` + `componentDidCatch`). Shows a centered card: RotateCcw icon, "Something went wrong", description, "Try again" button that calls `setState({ error: null })`.

Wired into the router's `page()` helper (`src/router/index.tsx`) — every lazy-loaded page is now automatically wrapped: `<ErrorBoundary><Suspense><Comp /></Suspense></ErrorBoundary>`.

### NotFoundPage (`src/pages/NotFoundPage.tsx`)
Full-viewport 404 page on `var(--surface-page)`. Large semi-transparent "404" in `var(--uc-indigo)`, "Page not found" heading, descriptive subtitle, "Back to feed" `PrimaryBtn`.
