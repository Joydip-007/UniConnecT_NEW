# Klipy Attribution Guideline

## 1. Attribution is Mandatory

To ensure a consistent and high-quality experience across all platforms, applications using the KLIPY API must include clear attribution.

> **Compliance Note:** Meeting these branding requirements is a mandatory criterion for final approval of your application's production request.

---

## 2. Search Bar Placeholder (Required)

The search bar used for KLIPY content must clearly identify the content source.

### Requirement

Set the search bar placeholder text to:

```text
Search KLIPY
```

---

## 3. Watermark on Sent Cards (Strongly Recommended)

When a user sends a GIF, Sticker, Clip, or Meme, KLIPY strongly recommends displaying a watermark on the message card.

### Guidelines

- Use the semi-transparent white KLIPY logo.
- Place it in the bottom-left corner.
- Keep it visible but minimally distracting.

---

## 4. Logo in Picker / Selector (Optional)

Display the **Powered by KLIPY** logo near the search bar or preview area when using a content picker.

---

## 5. Brand Assets

Official KLIPY brand assets are available through a Google Drive link.

Available assets:
- PNG logos
- SVG logos
- Light-theme versions
- Dark-theme versions

---
