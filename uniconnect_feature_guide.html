Codebase Findings

ℹ️
All findings are based on live code analysis of apps/api/src/ and apps/web/src/features/. File references are exact paths.

Learning Page — What Exists

exists Skill Paths

Table: skill_paths + skill_path_units. Service at modules/learning/service.ts with enroll, complete unit, abandon. Unit types: read | video | exercise | quiz. Tenant-scoped (university_id nullable = platform-wide).

exists Daily Quiz

Tables: daily_quiz_slots + daily_quiz_attempts. Worker at workers/quiz.worker.ts generates slots at midnight via the Bull learning queue. Uses fallback static questions when pool is empty.

exists Streak / Stats

learning_stats table tracks current/longest streak, freeze mechanics, and reminder dates. Hourly Bull job (learning.worker.ts) at cron '10 * * * *' sweeps midnight resets.

exists Badges

badges + user_badges tables. Badge queue fires on: unit_completed, streak_milestone, path_completed, quiz_win. Rarity system (epic/rare/common) based on holder count.

exists Learning Queue

Bull queue (queues/learning.queue.ts). Workers piggyback on it. Quiz worker listens to learningQueue.on('completed') to trigger slot generation.

missing AI Path Generation

No AI model integration for generating new learning paths dynamically. Current paths are seeded manually (migration 087_seed_platform_skill_paths.ts). No LLM call anywhere in learning module.

missing AI Quiz Generation

Quiz questions come from existing quiz-type units OR the hardcoded FALLBACK_QUESTIONS array in quiz.worker.ts. No LLM generation of quiz questions at runtime.

Study Groups — What Exists

exists Group Types

Schema: z.enum(['department', 'club', 'batch', 'research', 'interest', 'other']). No "academic" type currently. All types have equal access to flashcard decks.

exists Flashcard Decks

Tables: group_flashcard_decks, group_flashcards, group_flashcard_reviews. Spaced repetition via SM-2 algorithm in spacedRepetition.ts. ALL group types can access decks currently.

exists Shared Notes

Table: group_shared_notes (id, group_id, university_id, created_by, title, body). Notes are TEXT only — no file attachments. Body max 10,000 chars.

exists Study Sessions

Table: group_study_sessions + RSVP table. Sessions have title, description, location, online flag, capacity. Members auto-RSVP as creator.

exists Role Restriction

allowed_role column on groups: z.enum(['student','alumni','faculty','admin']). Students can only create student-restricted groups (resolveAllowedRoleOnCreate in service).

missing Academic Group Type

No "academic" group type exists. The schema needs: new enum value, faculty-only creation guard, LMS feature flags, and AI automation toggle at the group level.

missing File Upload in Notes

Notes body is pure text. No attachment column in group_shared_notes. Upload service exists (services/upload.service.ts) using S3/R2 presigned URLs — can be reused.

missing LMS Features

No gradebook, assignment submission, course modules, or attendance tracking. Must be built as new sub-features of academic groups.

New File: services/ai.service.ts

// apps/api/src/services/ai.service.ts
// Uses FREE Gemini 1.5 Flash via @google/generative-ai
import { GoogleGenerativeAI } from '@google/generative-ai'
import { env } from '../config/env'

const genAI = new GoogleGenerativeAI(env.GEMINI_API_KEY)
const model = genAI.getGenerativeModel({ model: 'gemini-1.5-flash' })

// Generate 5 quiz questions for a department
export async function generateQuizQuestions(department: string, count = 5) {
  const prompt = `Generate ${count} multiple-choice quiz questions for ${department} students.
Return ONLY valid JSON array: [{"q":"...","options":["A","B","C","D"],"answer":0}]
answer is 0-indexed. No markdown, no explanation.`
  const result = await model.generateContent(prompt)
  return JSON.parse(result.response.text().trim())
}

// Generate a new skill path with units
export async function generateSkillPath(category: string) {
  const prompt = `Create a 7-day learning path for "${category}".
Return ONLY valid JSON: {
  "title":"...", "description":"...", "difficulty":"beginner|intermediate|advanced",
  "units":[{"title":"...","type":"read|video|exercise","content":{"text":"..."}}]
}`
  const result = await model.generateContent(prompt)
  return JSON.parse(result.response.text().trim())
}

// Generate flashcards for academic groups
export async function generateFlashcards(topic: string, count = 10) {
  const prompt = `Create ${count} flashcards for "${topic}".
Return ONLY valid JSON array: [{"front":"Question or term","back":"Answer or definition","hint":"optional hint"}]`
  const result = await model.generateContent(prompt)
  return JSON.parse(result.response.text().trim())
}

Academic LMS Groups

⚠️
Academic groups are faculty-only to create. Faculty becomes the group admin. Other roles retain existing group creation abilities but cannot create "academic" type groups.

LMS Features Inside Academic Groups

new Course Modules

Structured course content organized in weeks/modules. Faculty creates modules, members access them sequentially. Stored in academic_group_modules table.

new AI Flashcard Decks

Flashcard decks moved exclusively to academic groups. Faculty toggles "AI Auto-Generate Flashcards" setting. AI posts new decks at 8 AM daily.

new Assignments

Faculty posts assignments with deadline, description, and file attachments. Students submit via file upload. Grades stored in academic_submissions.

new Gradebook

Faculty-only view showing all member grades across assignments. Visible only to group owner/admin (faculty). Students see their own grades.

new Attendance

Linked to study sessions. Faculty can mark session as requiring attendance. Members RSVP or check in. Attendance report for faculty.

new Announcements

Faculty pinned announcements (extends existing pinned_text). AI daily posts show as "AI Tutor" announcements. Toggle-able by faculty.

// middleware/academicGroup.ts
export async function requireAcademicGroup(req, res, next) {
  const { groupId } = req.params
  const group = await db('groups').where({ id: groupId }).first('type')
  if (!group || group.type !== 'academic') {
    return res.status(403).json({ error: 'Flashcard decks are only available in academic groups' })
  }
  next()
}

AI Daily Scheduler — Automated Content Posting

The AI acts as an autonomous "bot" that posts daily at a fixed time. This piggybacks on the existing Bull queue system — no new infrastructure needed. The bot uses a system user (like the existing "campus bot" from migration 063).

Daily Schedule (per university timezone):

  01:00 → AI generates quiz questions for each dept (replaces/supplements quiz.worker static fallback)
  06:00 → AI generates new skill path drafts (1 per category, admin reviews)
  08:00 → For each academic group with AI enabled:
              • Post AI-generated flashcard deck (if ai_flashcards_enabled)
              • Post "today's quiz" announcement
              • Post "recommended learning path" message

Implementation: Single new worker file + new Bull queue
Bot identity: Reuse campus_bot user (migration 063 already creates it)

New Worker: workers/ai-content.worker.ts

// apps/api/src/workers/ai-content.worker.ts
import { aiContentQueue } from '../queues/ai-content.queue'
import { generateQuizQuestions, generateFlashcards } from '../services/ai.service'
import { db } from '../config/db'
import { logger } from '../utils/logger'

// Cron: daily at 1 AM UTC (adjust per university tz in logic)
aiContentQueue.add({}, { repeat: { cron: '0 1 * * *' }, jobId: 'ai-daily-content' })

aiContentQueue.process(async () => {
  const universities = await db('universities').where({ is_active: true }).select('id', 'timezone')

  for (const uni of universities) {
    // 1. Generate AI quiz questions for each department
    const departments = await db('profiles')
      .where({ 'users.university_id': uni.id })
      .join('users', 'users.id', 'profiles.user_id')
      .whereNotNull('profiles.department')
      .distinct('profiles.department')

    for (const { department } of departments) {
      try {
        const aiQuestions = await generateQuizQuestions(department, 5)
        // Store to ai_generated_quiz_pool for quiz.worker to pick up
        await db('ai_quiz_pool').insert({
          university_id: uni.id, department,
          questions: JSON.stringify(aiQuestions),
          generated_at: new Date(),
        })
      } catch (err) {
        logger.error('AI quiz gen failed', { department, err })
      }
    }

    // 2. Post to academic groups with AI enabled
    const academicGroups = await db('groups')
      .where({ university_id: uni.id, type: 'academic' })
      .whereRaw("(ai_settings->>'ai_flashcards_enabled')::boolean = true")

    for (const group of academicGroups) {
      const topic = group.department || group.name
      const cards = await generateFlashcards(topic, 10)
      // Insert AI deck + cards using bot user as created_by
      // Notify group members via notification queue
    }
  }
})
